# ATLAS BET INTELLIGENCE — CORE v1

Готовый демонстрационный MVP для просмотра событий, сравнения коэффициентов по одинаковым рынкам и расчёта теоретического арбитража. Не подключён к реальным букмекерам, не размещает ставки, не гарантирует прибыль.

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

Откройте адрес, показанный Streamlit (обычно http://localhost:8501).

## Запуск через Streamlit Community Cloud

1. Загрузите **все файлы из архива** в публичный репозиторий GitHub.
2. Откройте https://share.streamlit.io/ и создайте приложение из репозитория.
3. Main file path: `app.py`.
4. После запуска выберите «Демо». Доступность Streamlit Cloud зависит от региона и условий сервиса.

## Подключение реальных данных

Переключатель «JSON URL» ожидает HTTPS-адрес вашего адаптера, возвращающего JSON вида:

```json
{"events":[{"sport":"Футбол","name":"Команда 1 — Команда 2","status":"prematch","market":"1X2 / основное время","outcomes":["1","X","2"],"quotes":[{"bookmaker":"Источник 1","outcome":"1","odd":2.5},{"bookmaker":"Источник 2","outcome":"X","odd":3.7},{"bookmaker":"Источник 3","outcome":"2","odd":3.2}]}]}
```

Важное условие: все `quotes` в одном событии должны относиться к одному и тому же рынку, периоду и правилам расчёта. Адаптер должен проверять идентичность событий, актуальность и доступность коэффициентов. Не вводите секретные API-ключи в публичные поля или файлы GitHub. Интеграция с API-SPORT.ru требует проверки реального формата ответа и наличия коэффициентов по отдельным букмекерам.

## Ограничения

Это рабочий прототип на демонстрационных данных, а не подтверждённый live-сканер. Не учитывает комиссии, лимиты, округление ставок, задержки, отмены и правила расчёта. Не осуществляет транзакций.
